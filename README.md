# How to get added to a repository

## On Microsoft Teams

There should be a post in Microsoft Teams about getting access to a repository.

Reply in that post and:

1. Paste **only your GitHub username** (your nick). Do not paste the full profile link.
   - Write: `octocat`
   - Do not write: `https://github.com/octocat`
2. **Mention Piotr Kojałowicz with @**, so the request is addressed to him.

## If there is no such post

Send an email to **pkojalowicz@pjwstk.edu.pl**.

In the email, say **which Microsoft Teams group you are writing from**. Give the **full name of the group**. Use the **exercise group** name when you have one.

Also include your GitHub username (the nick only, not the full link).

# Jak zostać dodanym do repozytorium

## Na Microsoft Teams

Na Microsoft Teams powinien być post o dostępie do repozytorium.

Odpowiedz w tym poście i:

1. Wklej **sam nick GitHuba**. Nie wklejaj całego linku do profilu.
   - Napisz: `octocat`
   - Nie pisz: `https://github.com/octocat`
2. **Oznacz Piotra Kojałowicza za pomocą @**, żeby zgłoszenie było skierowane do niego.

## Jeśli takiego posta nie ma

Napisz maila na adres **pkojalowicz@pjwstk.edu.pl**.

W mailu podaj, **z jakiej grupy na Microsoft Teams piszesz**. Podaj **pełną nazwę grupy**. Najlepiej użyj nazwy **grupy ćwiczeniowej**.

Dopisz też swój nick GitHuba (sam nick, bez całego linku).
